# Overview

这套文档记录三条同步推进的工程学习线：AI 学习、从前端扩展到后端与生产交付的全栈学习，以及用真实代码验证知识的开源项目研读。

## 文档定位

- `docs/ai/`：AI 学习大类入口；现有 Phase 0 到 Phase 4 继续保留原路径。
- `docs/full-stack/`：全栈学习入口、路线与模块笔记。
- `docs/open-source/`：开源项目研读方法、路线与逐项目累计笔记。
- `practice/`：内部练习目录，不作为站点入口；稳定例子整理后进入主题笔记代码块。
- `docs/projects/`：项目型学习任务的目标、待完成事项和实践记录。
- `docs/resources/`：课程、论文、工具和术语表。

## 学习主线

### AI 学习

1. Phase 0：建立 LLM 基础直觉。
2. Phase 1：掌握 AI workflow 和 Agent 产品设计。
3. Phase 2：跑通 QLoRA / SFT 微调入门。
4. Phase 3：逐步补齐 eval、serving、memory、retrieval 和 agent orchestration。
5. Phase 4：作为研究方向储备，不作为当前最高优先级。

入口：[AI 学习](./ai/00-overview.md)

### 全栈学习

1. 建立后端运行时、网络与 HTTP 请求链路的心智模型。
2. 补齐 API、服务架构、数据库、事务、鉴权与安全。
3. 掌握缓存、队列、测试、可观测性、部署与回滚。
4. 独立完成一个可上线、可运维的全栈产品闭环。

入口：[全栈学习](./full-stack/00-overview.md)

### 开源项目研读

1. 围绕 AI 或全栈当前主题选择一个项目和一个源码问题。
2. 建立最小仓库地图，沿一条端到端调用链阅读实现。
3. 用测试、日志、断点、失败注入或最小改动验证理解。
4. 复述设计取舍，将可迁移结论链接回对应主线。

入口：[开源项目研读](./open-source/00-overview.md)

## 阅读顺序

1. 从 [学习首页](./README.md) 选择 AI、全栈或开源项目研读。
2. 阅读该大类的 Roadmap 和 `00-overview.md`。
3. 进入当前主题笔记，记录理解、实践、代码片段和问题。
4. 在共享的 [Progress](./progress.md) 中维护三条学习线各自唯一的下一步。
