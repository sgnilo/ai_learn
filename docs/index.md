# AI Learn Docs

这里是 AI 学习计划、知识笔记、项目沉淀和资源索引的文档站点入口。后续部署到 GitHub Pages 时，可以从这个页面进入完整学习路线，也可以按阶段、项目或资源快速复习。

## 快速入口

| 入口 | 用途 |
| --- | --- |
| [Overview](./overview.md) | 快速理解这套学习体系、当前优先级和文档维护方式 |
| [Roadmap](./roadmap.md) | 查看完整 AI 学习路线、阶段目标和进度记录 |
| [Sitemap](./sitemap.md) | 按目录浏览所有文档页面 |
| [Practice](./practice/README.md) | 查看代码练习目录、运行方式和练习建议 |

## 复习路径

1. 先读 [Overview](./overview.md)，确认当前学习重点。
2. 再进入 [Roadmap](./roadmap.md)，按阶段推进。
3. 每次复习一个主题时，从对应阶段的 `00-overview.md` 进入具体笔记。
4. 需要查工具、论文、课程和术语时，进入 [Resources](./sitemap.md#resources)。
5. 需要把知识落到代码时，进入 [Practice](./practice/README.md) 和 [Projects](./sitemap.md#projects)。
