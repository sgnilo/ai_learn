## 阶段目标

建立真正的 LLM 工程直觉，而不是只停留在会调 API。

## 必学主题

- Tokenizer
- Embedding
- Transformer
- Attention
- LM Head / Logits / Loss
- Context Window
- KV Cache
- Inference
- RAG
- Function Calling
- Agent Workflow
- 本地模型部署

## 必做实践

- 手搓 mini GPT：nanoGPT / minGPT
- 本地部署模型：Ollama、vLLM、LM Studio
- 观察推理指标：显存、token/s、context 长度、量化效果

## 阶段完成标志

- 能解释 transformer 的基本工作机制
- 能独立本地部署一个模型
- 理解 inference 的性能瓶颈
- 能区分 agent 与 workflow
