# Engineering Learn

这个仓库把 AI、全栈与开源项目研读分成三条并行学习线，并将学习文档和内部练习分开维护：

- [docs/](./docs/)：AI、全栈、开源项目研读路线，主题笔记、项目沉淀和资源索引。
- `practice/`：学习过程中的内部代码练习、测试和工程配置。练习完成后，将稳定例子整理进对应主题笔记。
